# Search Indexing Checklist

External indexing is not automatic and is not claimed by this repository.

## Google Search Console

1. Add the Pages property: `https://jdlongmire.github.io/triadic-reality-theory/`.
2. Verify ownership using a supported Google method available for the account/property.
3. Submit `https://jdlongmire.github.io/triadic-reality-theory/sitemap.xml`.
4. Inspect the home, Accessible, and Technical URLs.
5. Record first observed indexing dates rather than assuming submission equals indexing.

## Bing Webmaster Tools

1. Add the same Pages site.
2. Verify ownership or import the verified Search Console property where supported.
3. Submit the sitemap.
4. Inspect crawl/index coverage and record observed state.

## Baseline queries to observe, not manipulate

- "Triadic Reality Theory"
- "Triadic Reality Theory Longmire"
- "logic information action ontology"
- "representability actualizability ontology"
- "irreducible co-primitives logic information action"

Rankings are measurements, not completion criteria.
