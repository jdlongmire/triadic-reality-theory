# Quantum Adversarial Stress Test

**WP:** WP-TRT-QSA-0001  
**Date:** 2026-09-30  
**Status:** adversarial pass v1  
**Question:** Does the Level 1 split survive major quantum interpretation families without changing the Level 0 canon?

## Test architecture

Level 0 remains:

$$\boxed{\chi \equiv \mathcal{A}(I\mid L)}$$

Level 1 distinguishes:

- \`Inst(σ)\`: physically instantiated state-information;
- \`Spec(α,σ,q)\`: derived action-role fixing bounded claim q;
- \`Settled(α,q,χ_q)\`: derived action-role/result settling determinate fact χ_q;
- \`χ_q\`: determinate actuality relative to q.

The stress test asks whether these types can describe rival quantum interpretations without building one interpretation into TRT.

## Pass/fail criteria

A case **passes** if TRT can type it without:

1. treating superposition as simultaneous contradictory determinate facts under one fixed q;
2. assuming all observables possess pre-existing definite values;
3. requiring a conscious observer;
4. defining decoherence as unique-outcome settlement;
5. redefining primitive Action;
6. multiplying co-primitives;
7. assuming temporal order from the notation;
8. treating physically instantiated ψ as unreal merely because q is unsettled.

A case **fails** if its own ontology requires contradictory settled χ_q under exactly one fixed q, or if QSA can describe it only by violating the frozen notation.

## Case 1: textbook/projective-collapse family

### Input

A prepared ψ is physically instantiated:

\`Inst(ψ)\`.

A measurement interaction fixes an observable/context q:

\`Spec(α,ψ,q)\`.

A projective-collapse interpretation then treats one outcome as the realized measurement result.

### Typing

Candidate:

\`Settled(α,q,χ_q)\`.

The state may be under-determinate relative to q before settlement while fully determinate as ψ.

### Result

**PASS as a typing.**

QSA can represent collapse without making collapse part of the hard core. Collapse is one candidate physical mechanism by which a settling relation is realized.

### Risk

Do not infer that the existence of \`Settled\` proves physical collapse.

## Case 2: decoherence without an added unique-outcome postulate

Environmental interaction suppresses interference in a dynamically preferred/pointer structure. The literature treats decoherence/einselection as selecting robust states/observables, while the unique-outcome question remains interpretation-sensitive.

### Typing

Where the physical model warrants it:

\`Spec(α,ψ,q)\`.

But not by definition:

\`Settled(α,q,χ_q)\`.

### Result

**PASS, with discipline.**

Decoherence fits naturally as a candidate specifying action while remaining distinct from settlement.

### Risk

The current TRT Born-rule belt sometimes speaks as if decoherence “selects” a co-admissible set and a later A selects one member. QSA should replace this overloaded selection vocabulary with specification/stabilization versus settlement.

## Case 3: Everett / Many-Worlds

Everettian approaches retain unitary evolution and treat the universal quantum state as fundamental. Decoherence is commonly used to identify emergent branch/world structure; definite records are branch-relative rather than produced by a fundamental collapse.

### Typing option A: branch-index q

Let q include branch/context index b:

\`q_b = <x,P,c,r,b>\`.

Then branch-relative records may satisfy:

\`Settled(α,q_b,χ_{q_b})\`.

Different branches can contain different determinate facts without contradiction because q differs by branch/context.

### Typing option B: global single-outcome q

For a global q demanding one unique outcome across the entire universal state, Everett does not generally supply \`Settled(α,q,χ_q)\`; the universal state remains under-determinate relative to that single-outcome q while containing branch-relative determinate records.

### Result

**PASS as a rival typing; NO TRT verdict on MWI from QSA alone.**

QSA does not force MWI. It also does not refute MWI merely because multiple branch-relative outcomes exist.

### Falsification condition

If an Everettian ontology requires both P and not-P to be settled under literally the same q, with branch/context held fixed rather than indexed, it would conflict with L3/QSA. Branch-relative difference by itself is not contradiction.

## Case 4: Bohmian mechanics

Bohmian mechanics supplements the wave function with an actual configuration of particle positions evolving under a guiding equation. It is contextual with respect to general quantum observables; it does not require every operator to correspond to a pre-existing intrinsic property.

### Typing

- wavefunction/state: \`Inst(ψ)\`;
- actual configuration: candidate determinate state-level fact(s) \`χ_q\` for appropriately bounded position/configuration q;
- measurement interactions: derived specification/settlement roles as appropriate.

### Result

**PASS.**

QSA does not require Bohmian hidden variables, but it can type a theory in which some determinate physical variables coexist with under-determinate/operator-relative information.

### Risk

Do not equate “Bohmian position is definite” with “all observables are noncontextually definite.”

## Case 5: contextuality / Kochen-Specker

Kochen-Specker blocks a broad class of noncontextual global value assignments. It does not require the conclusion that a single fixed measurement record is both P and not-P.

### Typing

QSA's q already contains context/respect. This is a feature, not an escape hatch, provided q is fixed before evaluation.

The theory must not infer:

“for every representable observable P, there exists a context-independent χ_P before specification/settlement.”

### Result

**PASS and SUPPORTIVE OF THE TYPE DISCIPLINE.**

Contextuality is a direct reason not to identify the representable domain with one global row of pre-assigned definite values.

### Risk

QSA must not turn q-indexing into post-hoc redefinition. The context is fixed before the truth/value claim is evaluated.

## Case 6: modal/value-state interpretations

Modal approaches distinguish a dynamical quantum state from value states/properties that are definite at a time.

### Typing

This maps naturally, though not identically, onto:

- physically instantiated informational/dynamical state: \`Inst(σ)\`;
- determinate bounded value fact: \`χ_q\`.

### Result

**PASS as a structural comparison.**

Do not claim TRT is a modal interpretation merely because the type distinction resembles one.

## Case 7: paraconsistent or non-bivalent quantum descriptions

A formalism may represent superposition using non-classical truth values, contradiction-like structures, or non-bivalent semantics.

### Typing

Such content can reside in the representational/state sector without being automatically promoted to contradictory determinate χ_q.

The QSA challenge is empirical/ontological:

> Does a physically instantiated and settled fact under one fixed q require both P and not-P as determinate actuality?

### Result

**PASS provisionally.**

Non-classical representation does not itself falsify L3 at the determinate-fact layer.

### Genuine falsifier

A verified physical case requiring:

\`Settled(α,q,χ_q[P])\`

and

\`Settled(β,q,χ_q[not-P])\`

for the same fixed q and same determinate fact-status, with no contextual, temporal, branch, subject, or predicate shift.

## Case 8: no-measurement / unitary evolution

A closed or effectively isolated quantum system evolves unitarily without a measurement context being imposed.

### Typing

\`Inst(ψ(t))\` may hold across the evolution.

No \`Spec\` or \`Settled\` relation need be asserted for an arbitrary q.

### Result

**PASS.**

This demonstrates why Spec and Settled cannot be primitives or mandatory roles of every action occurrence.

## Cross-case findings

### Finding A: state actuality is not fact actuality

Every tested family can distinguish, in some form, between a state description/ontology and determinate records or values. The interpretations disagree about what makes the latter true and whether all outcomes obtain branch-relatively.

QSA therefore has warrant to distinguish \`Inst(σ)\` from \`χ_q\` without claiming that one interpretation has been established.

### Finding B: q-relativity is essential

Quantum contextuality and incompatible observables make global unindexed value assignments unsafe. q must be fixed before a determinate claim is evaluated.

### Finding C: decoherence is downstream and insufficient by definition for unique settlement

Decoherence can support \`Spec\` where a pointer/context structure is physically stabilized. QSA must not equate decoherence with \`Settled\`.

### Finding D: LEM, bivalence, and definite-value realism remain distinct

QSA's determinate-fact claim is local:

> once χ_q is settled under fixed q, the bounded proposition is determinate.

It does not imply that every observable possessed a definite value before q was specified/settled.

### Finding E: MWI is not forced by state-instantiation

Recognizing \`Inst(ψ)\` as physically real does not entail that every represented alternative is a global χ_q. Everett adds an ontological interpretation of the unitary state/branch structure beyond the bare distinction.

### Finding F: MWI is not refuted merely by multiple outcomes

If outcomes are branch-relative, they correspond to differently indexed q. A contradiction requires same q.

## Adversarial attacks on QSA itself

### Attack 1: “q is an escape hatch”

Response: q is fixed before evaluation. Post-hoc modification invalidates the test. QSA should require q-registration in any severe test.

### Attack 2: “Settled just means classical by definition”

Response: Settled is a status relation, not a mechanism. QSA still owes an operational criterion for when a physical record warrants the predicate.

**OPEN BURDEN:** define an observer-independent settlement criterion.

### Attack 3: “Inst is already actuality, so χ is redundant”

Response: Inst is state actuality; χ_q is determinate fact actuality under bounded q. The distinction is substantive only if cases exist where Inst(σ) holds while q remains unsettled. Quantum superposition provides the principal stress case, but the ontology must not depend exclusively on QM.

**OPEN BURDEN:** provide at least one non-quantum structural analogue.

### Attack 4: “Spec smuggles measurement into ontology”

Response: Spec is a derived action role, not a primitive and not necessarily measurement. But its physical criterion remains open.

**OPEN BURDEN:** characterize specification without observer language and without defining it solely by later settlement.

### Attack 5: “L3 only appears at the end”

Response: QSA does not narrow canonical L3 to the endpoint. It merely makes its determinate-fact constraint explicit at χ_q. CORE-0001's broader admissibility role remains.

## Verdict

**QSA TYPE SPLIT SURVIVES ADVERSARIAL PASS v1.**

No tested interpretation family forces abandonment of:

- one primitive Action;
- physical state-instantiation distinct from determinate fact actuality;
- derived specification;
- derived settlement;
- q-relative χ_q;
- Level 0 χ ≡ A(I | L).

The pass does **not** establish a preferred interpretation of quantum mechanics, a physical mechanism of settlement, global bivalence, or a derivation of the Born rule.
