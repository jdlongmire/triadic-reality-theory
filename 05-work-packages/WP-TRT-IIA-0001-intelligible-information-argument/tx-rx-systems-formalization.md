# IIA TX/RX Systems Formalization

Status: ACTIVE
Date: 2026-10-01

## Systems abstraction

TX/RX is a heuristic systems model, not a premise asserting an intentional
transmitter.

```text
Source domain W
  -> state-sensitive interaction/channel Ch
  -> receiver R
  -> internal representation C
  -> inferential transformation N
  -> external validation V
  -> warranted output / correction
```

Necessary distinction:

- source: that about which information is acquired;
- transmitter: an intentional encoder, which is NOT assumed;
- channel: physical or causal relation preserving discriminable dependence;
- receiver: system whose states vary with source states;
- representation: receiver state used as being about a source/domain;
- validation: relation/process constraining representation by external correctness.

## Receiver adequacy

Receiver adequacy is multidimensional:
A_stat = sensitivity to statistical structure;
A_gen = generalization beyond samples;
A_sem = stable aboutness/grounding;
A_true = truth tracking;
A_norm = rationally governed inference.

No axiom states that A_stat entails the others.

## Correspondence thesis

IIA concerns the conjunction:

```text
tractable(W) AND adequate(R,W)
```

rather than either term independently.

The rational-ground hypothesis attempts a common explanation. Competing hypotheses
may instead give independent genealogies for W and R.

## Key control

"How can there be RX without TX?" is rhetorically suggestive but formally unsafe
because source structure does not entail intentional transmission. The defensible
question is:

How does an ontology account jointly for a recoverably structured source domain and
receivers capable of converting causal/statistical dependence into truth-tracking,
rationally assessable representation?
