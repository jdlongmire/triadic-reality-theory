# Notebook 03: Action and Dynamic Stability Principle

**Status:** Candidate refinement, not canonicalized.

## Proposed DSP
Every physically actual configuration, whether changing or stable, is necessarily sustained through fundamental Action. Stability represents persistence of a logically invariant informational configuration through ongoing actualization.

## Existing canonical tension
WP-TRT-CORE-0001 defines A as fundamental non-temporal state transition/change; actualization is a role of A. The DSP must not redefine A circularly as continued existence.

## Model comparison
1. Stable classical standing wave with underlying oscillation.
2. Steady-state dissipative system with flux.
3. Energy eigenstate with unobservable global phase and stationary Bloch ray.
4. Stationary quantum-field vacuum with nontrivial correlations.
5. Timeless or changeless countermodel.

## Questions
Can an A-transition occur at an ontological level while physical observables remain invariant? What are the distinguishable endpoints? Does ongoing mean temporal iteration or an ordering derivative of A? How is this more than relabeling persistence?

## Failure condition
DSP fails as a necessary theorem if a coherent actual yet actionless state is possible, or if its definition is tautological.
