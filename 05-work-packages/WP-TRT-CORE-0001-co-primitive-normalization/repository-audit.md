## Governing semantic changes

1. “Co-requiring primitives” is superseded on active canonical surfaces by **irreducible co-primitives**.
2. L₃ is ontological logical constraint, explicitly the three fundamental laws.
3. I∞ is unbounded informational representability/differentiation. Representability carries no modal entailment.
4. L₃-admissibility is necessary for D; sufficiency is open.
5. A is fundamental non-temporal state transition/change.
6. X/χ is actuality/what obtains and is not folded into the definition of A.
7. The canonical architecture is R → D → X/χ, with the first arrow explicitly a necessary L₃ filter rather than an equivalence.
8. The old compact identity is retained only as qualified schematic notation.
