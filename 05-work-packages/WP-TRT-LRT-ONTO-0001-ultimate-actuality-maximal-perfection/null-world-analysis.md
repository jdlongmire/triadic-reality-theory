# Null-World and Necessary-Actuality Analysis

**WP:** WP-TRT-LRT-ONTO-0001  
**Date:** 2026-09-19  
**Track:** A, pure derivation  
**Status:** first pass complete

## Question

Is absolute non-actuality metaphysically possible?

The target is not an empty physical universe. It is stronger:

N0 := there is no actuality whatsoever.

If N0 is impossible, then actuality is necessary:

not Diamond N0 -> Box Actuality.

Combined with the co-primitive result:

Box(Actuality -> (I AND L AND A)),

this yields:

Box(I AND L AND A)

at the structural-role level.

## 1. Distinguish four "empty" cases

### E1. Empty physical cosmos
No matter, fields, spacetime, particles, observers, or physical events.

This does not imply N0. Abstract, logical, modal, or other actuality may remain.

### E2. Empty domain
A formal model with no ordinary objects.

This is a semantic/model-theoretic construction and does not imply N0. The model, interpretation, or truths about it are represented in an actual metalanguage.

### E3. World with no contingent concrete entities
Only necessary or abstract structure obtains.

Again, not N0.

### E4. Absolute null
Nothing obtains in any ontological category. No concrete entity, abstract entity, fact, state, relation, truth-maker, event, law, actuality-conferring relation, or determinate condition obtains.

Only E4 is relevant.

## 2. First attack: "N0 obtains"

If N0 is formulated as:

"It is actually the case that nothing is actual,"

the formulation is self-defeating. The obtaining of N0 is itself an actuality/fact, contradicting its content.

Form:

N0 := not exists x Actual(x).

If N0 itself is an actual fact F_N0, then exists x Actual(x), contradiction.

But a defender can reject facts as entities or reject truthmaker commitments. Therefore this is not yet universal.

## 3. Second attack: possible-world semantics

Suppose:

Diamond N0.

Then there is some metaphysically possible world w0 such that at w0, nothing is actual.

If "world" is ontologically robust, w0 itself appears to be some actuality or total obtaining state, contradicting N0.

But if possible worlds are merely abstract representations, maximal consistent descriptions, or semantic indices, w0 need not be internally actual in the same ontological sense. The representation exists in the metalanguage/world doing the semantics.

Therefore possible-world semantics alone cannot settle N0 without assuming a world ontology.

**Result:** no proof from semantics alone.

## 4. Third attack: determinate nullity

For N0 to differ from:
- some actuality,
- another possible condition,
- incoherence,
- an incomplete description,

N0 must be determinate enough to have identity as the null condition.

This invokes at least I and L at the level of representation/admissibility. But it does not yet invoke A internally to N0.

Thus:

Representable(N0) -> I.

Possible(N0) -> L-admissibility.

Neither entails Actuality-at-N0.

**Result:** differentiability and logic constrain the representation of nullity but do not by themselves refute nullity.

## 5. Fourth attack: truth of possibility

If Diamond N0 is true, then at least one modal truth obtains: "N0 is possible."

This establishes some actuality of modal truth in the evaluating order. It does not establish actuality in the represented null world unless modal truths are world-internal or necessarily actual across worlds.

A move from "the proposition is true" to "something is actual in w0" would be a metalanguage/object-language equivocation.

**Result:** blocked.

## 6. Fifth attack: actuality as a transcendental precondition of possibility

Candidate argument:

P1. Metaphysical possibility is possibility-of-actuality, not merely formal representability.
P2. A condition is metaphysically possible only if it could obtain.
P3. "Could obtain" presupposes the category/status Actuality, even when the candidate condition contains no ordinary objects.
P4. Therefore actuality as an ontological category is necessary to modal possibility.
C. N0, understood as absence of the category/status of actuality itself, is not metaphysically possible.

This is promising but requires a distinction:

- **A as necessary ontological category/status**
versus
- **some actual x exists in every world.**

P1-P4 support the former more readily than the latter.

If A is the primitive actuality-conferring category, then a possible world in which A is available but realizes no object might still be proposed. TRT must decide whether "A with empty image" counts as actuality.

## 7. Empty-image problem

TRT currently models:

A: D -> X.

A function may mathematically have an empty image only if its effective domain is empty or no application occurs. But D need not be empty: logically admissible structures exist at least representationally.

The key ontological question is whether A denotes:
1. a standing actualizing capacity/principle that may actualize nothing, or
2. actualizing action only insofar as some admissible possibility is made actual.

Under (1), A could be present in a null-object world, but A itself would be actual, so N0 fails.

Under (2), if nothing is actualized then A does not obtain, and N0 remains formally describable.

The current TRT hard core calls A "actualizing action: the principle by which logically admissible possibility becomes determinate actuality." The word "principle" leans toward (1), while the map notation leans toward a functional role. This ambiguity must be resolved rather than exploited.

## 8. Sixth attack: self-negating absolute nothing

Absolute nothing cannot possess:
- identity,
- properties,
- modal status,
- laws,
- potential,
- relations,
- capacity,
- actuality.

Therefore "absolute nothing is possible" cannot mean that Nothing has the property of possibility. It must mean that a null condition belongs to the modal domain.

That statement can be coherently represented externally. No contradiction has yet been shown in the null condition itself.

This blocks a common rhetorical argument: grammatical predication about "nothing" does not automatically turn nothing into something.

## 9. Result

The pure derivation does **not yet prove**:

Box Actuality.

Absolute nullity is difficult to ontologize, but the strongest objections so far either:
- make nullity into an obtaining fact and thereby beg against it;
- rely on robust possible-world ontology;
- shift from external representation to internal actuality; or
- treat "nothing" as an object.

Therefore the research must not claim the stronger theorem yet.

## 10. What has improved

The analysis exposes a potentially stronger and cleaner claim:

**Necessary Actuality-Category Thesis (NACT):**

Box(CategoryOfActuality).

Any metaphysical possibility is a candidate for obtaining; therefore the actuality/non-actuality distinction is constitutive of modal space itself.

NACT is weaker than:

Box exists x Actual(x).

But if TRT's A denotes the actuality-conferring category/principle rather than an event token, NACT may support:

Box A

without proving that every world contains an actualized derivative object.

This may be the correct formulation of the user's co-primitive necessity thesis.

## 11. Revised target

Instead of requiring:

Box exists x Actual(x),

test:

Box L_role AND Box I_role AND Box A_role.

Where:
- L_role = logical admissibility is necessarily constitutive of any possible actuality;
- I_role = differentiability is necessarily constitutive of any possible actuality/modal alternative;
- A_role = the actuality/non-actuality distinction is necessarily constitutive of metaphysical possibility.

This is role necessity, not entity existence.

## 12. Interim disposition

- Absolute-null impossibility: **NOT PROVEN**.
- Box exists x Actual(x): **NOT PROVEN**.
- Necessary actuality-category thesis: **STRONG CANDIDATE**.
- Box A_role under a role/category interpretation of A: **MEDIUM, requires formal clarification of A**.
- Box(L_role AND I_role AND A_role): **MEDIUM candidate**.
- Necessary unified bearer: **UNTOUCHED / UNCERTAIN**.
