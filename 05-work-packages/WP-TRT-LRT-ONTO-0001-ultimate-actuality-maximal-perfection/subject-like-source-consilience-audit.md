# Subject-Like Source Consilience Audit

**WP:** WP-TRT-LRT-ONTO-0001
**Date:** 2026-09-23
**Status:** bounded consilience audit v0.1
**Target:** G_E + K_sem ->? SubjectLikeSource
**Controls:** TASR, ADF, ESR, Role/Ontology Firewall, no-smuggling

## 1. Target

Let G_E be the Unified Expressive Source candidate.

Let:

K_sem := <Reference, TruthAptness, Misrepresentation, ContentIdentity, CorrectnessNorm>.

Question:

G_E + K_sem ?=> SubjectLikeSource.

This is not a deduction from one semantic property. It is a unification/consilience test across independently identified constraints.

## 2. Minimal subject-like profile

Define SubjectLikeSource minimally as a unified source satisfying:

SL1. **Content locus:** differentiated content is intrinsic to the source's grounding operation rather than assigned wholly from outside.

SL2. **Reference locus:** determinate reference relations are intrinsic to that same source/order.

SL3. **Norm locus:** truth/correctness conditions are intrinsic to the content order rather than supplied by an external interpreter.

SL4. **Act attribution:** expressive acts are attributable to the same source that grounds the content and its logical/semantic relations.

SL5. **Unity:** SL1-SL4 are one grounding order, not independent primitives externally coordinated.

This definition does not include:
- phenomenal consciousness;
- human-style cognition;
- self-awareness;
- will;
- personhood;
- moral agency.

## 3. Constraint mapping

G_E already supplies candidate:
- non-derivative sourcehood;
- intrinsic L/I;
- expressive act;
- co-unity.

K_sem adds:
- determinate reference;
- truth-aptness;
- content persistence across satisfaction/failure;
- correctness/misrepresentation norm.

Together they require one ontology in which content, its correctness conditions, and its expression are jointly grounded.

This maps directly onto SL1-SL5.

## 4. Is the mapping merely definitional?

Potential objection:

SubjectLikeSource has been defined as "whatever satisfies the constraints," so the conclusion is trivial.

Control:

The label **subject-like** carries no proof weight. The substantive result is the integrated profile SL1-SL5.

Therefore distinguish:

IntegratedSemanticSource(g) := SL1 AND SL2 AND SL3 AND SL4 AND SL5.

Then:

G_E + K_sem ->? IntegratedSemanticSource(g).

Only afterward ask whether "subject-like" is an appropriate ontological classification.

This prevents terminological victory.

## 5. Impersonal primitive-semantic rival

H_PS can respond:

One impersonal ultimate structure primitively instantiates:
- content;
- reference;
- correctness norms;
- act;
- sourcehood;
- unity.

If genuinely one primitive essence explains all relations intrinsically, H_PS may satisfy the integrated profile while rejecting subject language.

Therefore:

IntegratedSemanticSource -/-> Subject

as a strict deductive theorem.

The disagreement becomes ontological interpretation unless an additional subject-specific property is derived.

## 6. Explanatory-cost comparison

If H_PS treats each semantic relation as an independent primitive:

<L,I,A,U,SRC,EXP,Ref,CorrectFor,...>

then it has not unified the constraints; it has collected them.

If H_PS supplies one independently intelligible impersonal nature from which those relations follow, it remains a strong rival.

The Source-Mind hypothesis proposes that content, reference, norm, and act are aspects of one source-order.

At this stage, that is a consilient unification claim, not a proof.

## 7. Misrepresentation pressure

Misrepresentation remains especially important.

The same source/order must preserve:
- content c;
- its reference target/condition;
- its correctness standard;
- an expressive act involving c;
while the represented condition may fail.

This requires semantic content to outrun current-state satisfaction.

An impersonal ontology can posit this structure, but cannot reduce it to bare occurrence/covariance without losing misrepresentation.

Thus K_sem is irreducible to thin E0 under the current audit.

## 8. Act/content co-attribution

The strongest subject-like pressure is co-attribution:

The source that grounds the content also grounds the act expressing that content.

Form:

Grounds(g,c)
AND Grounds(g,Correctness(c))
AND Source(g,A_c)
AND Unified(g,c,A_c).

This is stronger than:
- content existing in one realm;
- act occurring elsewhere;
- correctness supplied by a third relation.

Call this:

**Content-Act Co-Attribution (CACA).**

CACA is a substantive ontological relation.

It does not yet entail consciousness, but it makes "subject-like" more than a loose analogy.

## 9. Minimal Subject-Likeness Conjecture

**SLC-1:**

If one non-derivative unified source intrinsically grounds:
1. differentiated content;
2. determinate reference;
3. truth/correctness norms;
4. expressive act of that content;
5. content-act co-attribution;

then that source is minimally subject-like.

Formally:

IntegratedSemanticSource(g)
AND CACA(g)
?=> SubjectLike_min(g).

This is a classificatory/metaphysical conjecture, not a formal theorem.

## 10. What is still missing for Mind

Even if SLC-1 is accepted, Mind requires more.

Candidate missing bridges:
- intrinsic apprehension rather than merely content possession;
- reflexivity/self-presence;
- reasons-as-reasons;
- intentional sourcehood;
- perhaps agency/will.

Therefore:

SubjectLike_min -/-> Mind

at present.

## 11. No-smuggling audit

No physical mind, brain, organism, computer, AI system, language community, or physical information process is used as a premise.

No equation:
- reference = subject;
- correctness = mind;
- content = knowledge;
- act = agency;
- unity = consciousness;
- integrated semantic source = person.

**Audit:** PASS.

The bounded audit supports a stronger integrated ontology:

G_E + K_sem
->
candidate IntegratedSemanticSource.

same source grounds content + correctness + expressive act.

This warrants the label **subject-like** as a consilient classification more strongly than previous thin L/I/A did, but it does not deductively force subjecthood against a sufficiently unified primitive-semantic impersonal rival.

Therefore:

G_E + K_sem + CACA
->CNS
SubjectLike_min.

Status: **MEDIUM-HIGH consilient inference**, not theorem.

H_PS remains the principal live rival.
