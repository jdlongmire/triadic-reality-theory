# Source Principle Audit: Can Non-Derivative Act Be Source-less?

**WP:** WP-TRT-LRT-ONTO-0001
**Date:** 2026-09-23
**Status:** bounded ontology-class audit v0.1
**Target:** SP-A
**Controls:** ADF, ESR, TASR, no-smuggling

## 1. Target

SP-A candidate:

NonDerivativeAct(A) ?=> exists g Source(g,A).

The purpose is not to prove substance metaphysics. It is to determine whether genuine non-derivative act can be ontologically source-less or whether "act simply occurs" fails to provide an explanatory ontology.

## 2. Terminology

Act(A): actuality-conferring/obtaining role, not necessarily temporal motion.

Source(g,A): A is attributable to g as the non-derivative ontological locus/origin of the act.

Source does not initially mean:
- person;
- conscious agent;
- substance in the Aristotelian sense;
- temporal cause;
- efficient cause in a physical sequence.

Bearerless(A): there is no g such that Source(g,A).

## 3. Event ontology

Strongest rival:

A itself is a primitive event/fact. No bearer behind the event is required.

Form:

Exists(A) AND Primitive(A).

This avoids an enduring substance.

But two cases arise.

### E1: event as source

If the primitive event is itself that from which actuality obtains, then the event is functioning as the source term.

SP-A survives in generalized form:

exists g Source(g,A),

where g need not be a substance and may be the primitive event/process itself.

### E2: event without sourcehood

If A merely means "X obtains" and no source relation is admitted, then A risks collapsing into:

A := X-is-actual.

That restates actuality rather than grounding it.

Result: event ontology challenges substance-bearer language but does not clearly defeat generalized sourcehood.

## 4. Process ontology

A process ontology may treat becoming/activity as fundamental rather than locating act in a static bearer.

Again distinguish:

### P1: fundamental process as source

The process itself is the non-derivative actuality-source.

Then Source(g,A) is satisfied with g typed as process.

### P2: process as sequence requiring prior actual terms

If the process is defined through transitions among already actual states, it is derivative and cannot ground A upstream under TASR.

Result: process ontology may satisfy SP-A by broadening source beyond substance.

## 5. Structural ontology

A structural realist rival may propose that the ultimate ontology is structure with no objects/bearers.

To ground A, the structure must be more than abstract relation. It must be intrinsically actual and actuality-conferring.

If "structure" includes intrinsic act/sourcehood, then structure itself fills g.

If structure is only relational constraint, it supplies L-like form but not A.

If actual structure is simply asserted as primitive, it may terminate explanation but still functions as the ontological source/locus of actuality in the generalized sense.

Result: structural ontology does not eliminate sourcehood; it contests what kind of thing the source is.

## 6. Substance/source ontology

A substance ontology directly supplies:

Source(g,A).

This fits SP-A naturally but receives no automatic preference merely for using bearer language.

The audit therefore does not derive substance.

## 7. Generalized Source Principle

The original wording "act requires a bearer" is too strong.

The ontology-class audit supports a weaker and cleaner principle:

**GSP-A:**

If A is genuinely non-derivative and explanatory of actuality rather than synonymous with actuality, then there must be some ontological source/locus g such that A is intrinsic or attributable to g.

Formally:

NonDerivative(A)
AND Explanatory(A,X)
AND not Synonymous(A,X)
->
exists g Source(g,A).

g may be:
- substance;
- process;
- event;
- unified structure;
- another ontology type.

The theorem does not prejudge the category.

## 8. Source-less alternative

The remaining alternative is:

X obtains primitively, with no source/locus/explanation beyond the brute fact X.

This is coherent as an explanatory stopping position unless a stronger grounding principle is supplied.

But it abandons A as an independently explanatory primitive.

If:

A = "the brute fact that X obtains",

then A adds no explanatory content beyond X.

Thus the choice is:

1. A has genuine explanatory/source content -> generalized sourcehood;
2. A is only a label for brute actuality -> A is not independently explanatory.

This is the strongest current result.

## 9. Implication for co-primitivity

TRT currently treats A as an irreducible co-primitive role rather than a synonym for X.

Therefore, if that treatment is retained, GSP-A applies strongly:

A_role + non-derivative explanatory status
->
Source(g,A_role).

This does not yet identify g with Mind.

## 10. Integration with L and I

If the same ultimate g must also satisfy Functional Adequacy for L and I, then:

Source(g,A)
AND Grounds(g,L)
AND Grounds(g,I)
AND GroundsUnity(g,L,I,A).

The ontology-class audit therefore strengthens the unified-source bridge:

AdequateUltimateGround(g,G_req)
->
UnifiedIntrinsicSource(g,L,I,A).

Again, "source" is category-neutral.

## 11. Minimal agency consequence

Does generalized sourcehood yield Agent_min?

Not yet.

An event, process, or structure may be a generalized source without being an agent.

Therefore:

UnifiedIntrinsicSource(g,L,I,A)
?=> Agent_min(g)

remains OPEN.

The source audit narrows the issue: agency requires something beyond sourcehood, probably attribution of determinate content-expression to the source in a way that is not exhausted by impersonal obtaining.

## 12. No-smuggling audit

No physical example was used as a premise.

No assumption:
- source = substance;
- source = agent;
- source = mind;
- process = physical process;
- structure = physical structure;
- event = temporal physical event.

**Audit:** PASS.

## 13. Disposition

"Act requires a substance bearer": NOT DERIVED.

"Act requires a generalized source/locus if A is genuinely explanatory and non-derivative": STRONG CANDIDATE.

"Source-less brute actuality is incoherent": NOT ESTABLISHED.

"Source-less brute actuality preserves A as an explanatory primitive": NO; it collapses A toward a label for X.

Therefore GSP-A is adopted as the stronger research formulation:

NonDerivative(A)
AND Explanatory(A,X)
AND not Synonymous(A,X)
->
exists g Source(g,A).

## 14. Next bounded target

Test whether the unified source's content-expression supplies minimal agency:

UnifiedIntrinsicSource(g,L,I,A)
AND DeterminateExpression(g,I,L,A,X)
?=> Agent_min(g).

The decisive question is whether "determinate expression" can be fully impersonal without either:
- adding an external selector;
- reducing expression to brute obtaining;
- or importing another primitive beyond L/I/A/C.

This is a single class-level bridge and satisfies ESR.
