**WP:** WP-TRT-LRT-ONTO-0001
**Date:** 2026-09-19
**Status:** corrective audit v0.1
**Type:** methodological / dependency audit

## Purpose

Audit every major bridge move for:
- hidden grounding-existence premises;
- type crossing;
- primitive-count discounts;
- imported PSR/CGP;
- semantic/normative smuggling;
- Mind-specific free passes.

The audit distinguishes:
1. what TRT's Type-P hard core actually entails;
2. what follows only conditionally if an ultimate ground is proposed;
3. what remains a Type-B bridge hypothesis.

## 1. Hard-core result

TRT's current hard-core/derived result is:

[
Dightarrow(mathcal Llandmathcal Ilandmathcal A)
]

plus CPIT pair-failure/irreducibility and the canonical R/D/X distinctions.

This establishes constitutive dependence of determinate actuality on the co-primitive roles.

It does **not** by itself establish:

[
exists U,Ground(U,mathcal G).
]

No existential ground follows merely from the fact that D has constitutive conditions.

## 2. Grounding-existence premise

Several prior artifacts used formulations such as:

[
UltimateGround(g,chi)ightarrow AdequatelyGrounds(g,mathcal G).
]

This is valid as a conditional adequacy rule.

But some later language moved toward:

[
Dightarrow UGR(mathcal G)
]

as though an ultimate ground-role were itself derived.

That requires an additional premise:

**GRP, Grounding Requirement Premise:**

[
Dightarrowexists U,Ground(U,mathcal G).
]

GRP is NOT currently Type P.

GRP is a Type-B metaphysical bridge premise unless independently derived.

Treating GRP as established would import a weak grounding/PSR-like principle.

## 3. FAA correction

FAP remains valid only conditionally:

[
ProposedUltimateGround(U,mathcal G)
ightarrow
MustAdequatelyGround(U,mathcal G).
]

FAA compares proposed grounds.

FAA does not prove that there must be an ultimate ground.

Therefore change the interpretation:

Wrong:
"FAP establishes that D requires an ultimate ground."

Correct:
"Given a proposed ultimate-ground explanation of D/G, FAP specifies the workload it must discharge."

## 4. TASR correction

TASR is likewise conditional.

If X is proposed as the ultimate ground of Y, while X ontically presupposes Y, the proposal is dependency-circular.

[
Presupposes_{ont}(X,Y)
land
ProposedUltimateGround(X,Y)
ightarrow
GroundingCircularity(X,Y).
]

TASR eliminates/penalizes certain ground proposals.

It does not establish that some non-circular ground must exist.

## 5. CUB correction

CPIT/CUB says:

If a grounding theory distributes L/I/A across multiple proposed grounds, it owes an account of their co-unity.

CUB does not prove:
- a ground exists;
- one ground exists;
- co-unity has a further ground.

It is an explanatory-accounting rule conditional on entering the ground programme.

## 11. IAS audit

IAS receives no free capacities from the word "structure."

- activity;

- correctness;

## 12. Semantic-naturalization audit

Millikan/Neander remain legitimate Type-H intra-domain naturalization programmes.

They are not defeated because biology presupposes L/I/A.

But if their machinery is used to support a Type-B claim that wholly nonsemantic ground-nature is sufficient for all semantics, the reduction must be complete.

No-free-lunch questions:
- proper function;
- normal conditions;
- content determination;
- correctness/malfunction;
- producer/consumer architecture;
- truth-aptness.

No semantic term may be counted as reduced merely by renaming it functional.

## 13. Emergence audit

EPR says emergence cannot explain upstream the conditions required to specify the emergence relation.

But EPR does not forbid:
- derivative properties emerging within D;
- semantics emerging from nonsemantic biology if the emergence/reduction is genuinely specified using only already legitimate lower-level resources.

Therefore EPR must not be used as a universal anti-emergence slogan.

## 14. Chance audit

CPP blocks "chance" as a cost-free ultimate source.

It does not block stochastic Type-H models inside D.

Again the rule is typed.
